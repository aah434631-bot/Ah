# Ah · 产品广告创意与提示词

一个从产品白底图出发，生成广告创意与专业视觉提示词的 Skill。

## 工作流程

产品白底图 → 产品视觉诊断 → 核心传播命题 → 3 个创意方向 → 推荐方案深化 → 中英文提示词包 → 质量检查。

提供视频需求时，再扩展为 15–30 秒的分镜脚本。

## 输入

提供一张或多张清晰的产品白底图。可以补充品牌、真实卖点、目标人群、投放渠道、画幅和偏好风格；缺少这些信息时，Skill 会注明假设后继续制作方案。

## 输出

- 产品事实、视觉特征和待确认信息。
- 推荐方向、品牌方向、话题方向，共 3 个广告创意。
- 推荐方案的场景、道具、构图、灯光、镜头和留白设计。
- 中文主提示词、英文主提示词和负面提示词。
- 画幅建议、广告文案与后期排版说明。
- 按需提供的视频分镜与动态提示词。

## 使用示例

将本仓库作为名为 `product-ad-creative` 的 Skill 文件夹使用，在支持该 Skill 的环境中附上产品图并输入：

```text
使用 $product-ad-creative，根据这张产品白底图设计 3 个广告创意，
并输出推荐方案的中英文专业提示词。目标受众是年轻上班族，画幅 4:5。
```

视频需求示例：

```text
使用 $product-ad-creative，根据这张产品白底图，
设计一套 20 秒的广告方案，输出分镜和每个镜头的视频提示词。
```

## 创作原则

保留参考图中产品的外观与结构，区分已确认事实与创意假设。提示词用具体的光线、材质、空间和动作表达创意。准确的 Logo、价格、规格与长文案建议在后期完成。

本仓库提供创意流程和提示词，不包含图像或视频生成服务。
